# Agent Note: 砍掉多语言与用不上的功能壳

Status: implemented

## 背景

上游 AlgerMusicPlayer 带着一整套面向多人的功能：五门语言、睡眠定时、心动模式、独立桌面歌词窗、OpenCC 歌词翻译引擎，外加一个 android 空壳目录。一个人的自用魔改里，这些功能没有使用者，但每一项都在收维护税：改一条文案要在 5 份语言文件里同步，i18n 门禁还得跑跨语言 diff；桌面歌词是第二个渲染入口加一套独立 IPC。

## 决策

`4c061f0` 一次性把它们收掉：

- i18n 只剩 `zh-CN`，`scripts/check_i18n.ts` 的 `TARGET_LANGS` 置空，跨语言 diff 直接跳过（将来真加语言再登记）。
- 睡眠定时、心动模式空壳、独立桌面歌词窗及其 IPC 移除；歌词翻译引擎（OpenCC）移除。
- android 空壳目录删除。
- 明确保留：主窗口内的全屏歌词、热力图、MPRIS、双布局。

## 放弃的方案

**继续带着五门语言（改动前的状态）**：文案维护成本按语言份数翻倍，落在一个人身上就是每次改 UI 都要动 5 个文件；而这些语言没有目标用户，属于纯负债。

**保留独立桌面歌词窗**：主窗口已有全屏歌词能覆盖使用场景，独立窗口要维护第二个渲染入口、窗口生命周期与专属 IPC，收益不成立。

（本节理由由 `4c061f0` 的改动范围与保留清单还原——当时没有单独的讨论记录。）

## 影响

- 新增文案只改 `src/i18n/lang/zh-CN/*.ts`；`docs/subsystems/i18n.md` 记录了语言收窄后的完整规则。
- 恢复多语言不再是"打开开关"：语言文件已不在仓库里，要恢复得重新翻译并重设门禁目标语言。
- 这段历史留在 commit 与本文里；根 `AGENTS.md` 与 `DEV.md`（现已并入 `README.md`）里"五门语言同步"的旧表述已随之清理。
